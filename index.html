Perguntas frequentes

Os produtos são digitais?

Sim. Os materiais são entregues digitalmente, conforme as condições informadas no checkout de cada produto. Não há envio físico.

Preciso de conhecimento avançado?

Não. Os materiais são voltados a iniciantes e usam linguagem acessível, com exemplos para você acompanhar passo a passo.

Como faço para comprar?

Os links seguros de pagamento serão disponibilizados nesta página quando os produtos estiverem configurados na plataforma de vendas. Se você deixar seu e-mail na lista de espera, será avisado.

A planilha do "Dinheiro no Controle" é editável?

Sim. O e-book acompanha uma planilha financeira editável para você registrar receitas, despesas, dívidas e metas do seu jeito.

Os resultados são garantidos?

Os resultados variam de pessoa para pessoa e dependem de como cada um aplica o conteúdo. Nosso papel é entregar um material claro e prático para você começar.
